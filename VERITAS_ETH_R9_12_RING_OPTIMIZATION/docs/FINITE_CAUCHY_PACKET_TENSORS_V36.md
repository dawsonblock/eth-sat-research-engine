Evaluate the exact deformed Cauchy row products\n\n`P_Y(X) = product_i [(1-Y_i) + (2Y_i-1) sum_j W[x_i,x_j](t+2L*V) X_j]`.\n\nAll coefficients live in `(Z/2^p Z)[U]/(f(U))[V]/(V^ell)` with an irreducible `f` modulo two. On Boolean inputs `X_j^2=X_j`, so the unique multilinear representation is\n\n`P_Y(X) = sum_{S subseteq [k]} A_Y(S) product_{j in S} X_j`.\n\nImplementation uses a sparse dictionary with bitmask `S` as the monomial label. Each multiplication combines supports by `S | {j}`. This is exact for Boolean evaluations; it is **not** an ordinary formal-polynomial identity in unrestricted `X`.\n\n### Independent verification\n1.
