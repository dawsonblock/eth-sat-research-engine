# An explicit structured D.3 packing witness

This constructs and checks one explicitly labeled graph family without
allocating its edges or packets. It is a witness to the packing conditions
and their child-size implication for this family. It is **not** an execution
of the general conditional-expectation labeler, a recursive contraction,
or a proof that the implementation meets the manuscript's uniform bounds.
In particular `a=1` is used here for the packing lemma. It cannot be an
active call in the manuscript's schedule `a_d=2 sum_{j<=d} u_j`, where the
active parameters have `u_d>=1`: that schedule has positive even `a_d`.
This is therefore not a theorem-conforming recursive execution.

Fix radix `r`, even integer `delta>=4`, and a positive integer `c`. For
each ordered pair `(i,j)` of labels in `[r]`, take `c` disjoint copies of
the bipartite graph `K_(delta,delta)`. Label all row vertices of those copies
with `i`, and all column vertices with `j`. Copies belonging to distinct
label pairs are also disjoint. Thus each vertex has degree exactly `delta`,
each directed pair class has `H=c delta^2` edges, and

\[
D=r^2,\quad L=2,\quad M=D H,\quad |V|=2r^2c\delta.
\]

Since `delta` is even, `H` is even and no padding is needed. Number each
edge in a class from `0` to `H-1`. For `i<j`, packet `({i,j},k)` contains
edge `k` from class `(i,j)` in slot zero and edge `k` from class `(j,i)`
in slot one, for `0<=k<H`. For `i=j`, packet `({i,i},k)` contains edges
`2k` and `2k+1` from class `(i,i)`, for `0<=k<H/2`. Both maps have obvious
inverses, so every edge appears in exactly one slot and the orientation bit
matches its endpoints. Their number is

\[
\binom r2 H+rH/2=r^2H/2=DH/L=M/2.
\]

For each group `i`, there are `rH=M/r` row ports and `rH=M/r` column
ports. With one child edge per half-wire and no additional wire variables,
that child has `2M/r` wires. Consequently each side's `3M/r` bound and the
resulting `6M/r` child bound hold. These counts do not establish the tensor
identities or modes of the contraction construction.

For `r=64`, `delta=4`, and `c=2048`, this gives `H=32768`, `D=4096`,
`M=134217728`, and `67108864` packets. The sufficient D.3 inequalities
hold: `M=2D^2 delta`, `M>=LD=8192`, and `2L=delta`. Every group has
`2097152` row ports and as many column ports; its `4194304=M/32` child
half-wires are below both `3M/32` and `M/8`.

`RegularPackingWitness` in `symbolic_regular.py` stores only the three
integer parameters. Its edge-to-slot and slot-to-edge methods use exact
integer operations and do not enumerate the graph. Tests exhaust every edge
and slot of a small analogous family and sample boundary addresses in the
64-group family. A separately materialized 128-edge, radix-two instance
satisfies the D.3 numeric inequalities, and the existing implicit-packing
checker verifies its real slots and loads; its labeling is supplied directly,
not generated by the conditional-expectation algorithm. Those tests check
the implementation; the algebra above explains the family for all admitted
inputs. Fixed input caps keep this finite reference bounded.

Run the 64-group calculation with `python scripts/audit_d3_symbolic.py`.
The JSON result explicitly marks the general constructor, full contraction,
and active-schedule compatibility as unverified or false.

## Extension to multiple coordinates and an active root schedule

`MultiCoordinateRegularPackingWitness` generalizes the same explicit family
to `a`-symbol words on each side. For each ordered pair of words in `[r]^a`,
take `c` disjoint copies of `K_(delta,delta)` with those row and column
labels. Write `H=c delta^2`, `D=r^(2a)`, and `L=2^a`. The implementation
requires `delta` to be a multiple of `L` and at least `2L`, hence `H` is
divisible by `L`. Every directed class has exactly `H` edges, so no padding
is needed. Each coordinate and each symbol appears on `M/r` ports per side,
where `M=DH`.

For a directed row/column label pair, sort the two symbols independently in
every coordinate. If `e` coordinates have equal symbols, each packet has
`2^e` slots for each directed class; the other bits fix orientation. Given
a class offset `h`, write `h=index*2^e+copy_index`. The bits of
`copy_index` occupy the equal-symbol coordinates of the slot, while the
direction of the labels fixes its remaining bits. The inverse reads those
bits and reconstructs the directed pair and class offset. Thus this is a
bijection between edges and slots, with `M/L` packets. Per coordinate, a
group has `M/r` row half-wires and `M/r` column half-wires; if the described
child has exactly these half-wires and no extra wires, its size is `2M/r`.

There is an explicit symbolic **active-root** example, not a full run. Set
`r=64`, `a=2`, `delta=8`, `c=2^131050`, and `s=M=2^131080`. The root
schedule has `lambda=131080`, `u=1`, `a=2`, and its degree bound is
`Delta=ceil(s^(9/10))=2^117972`. Here `D=2^24`, `L=4`, and

\[
2D^2\Delta=2^{118021}\le M,\quad LD=2^{26}\le M,\quad 2L\le\Delta.
\]

Each group has `M/64` ports per side, so its half-wire count is `M/32`.
The witness stores integer parameters and computes individual slots on
demand; it does not allocate the graph or evaluate its tensors. In
particular, this does not replay the deterministic general labeler, build
the described children, prove the parent-to-child identity, or execute the
rest of the recursive schedule. Passing the numeric root checks alone is
not a uniform complexity proof. The tests exhaustively compare a materialized
4,096-edge two-coordinate analogue with the independent implicit-packing
checker and test this exact symbolic root schedule without replacing its
degree calculation.

Reproduce the compact root preflight with
`python scripts/audit_symbolic_theorem_root.py`. Its output reports the
exponent of `s` rather than printing integers with tens of thousands of
digits and explicitly marks child construction and contraction as unrun.

Reproduce that calculation without printing the 131,081-bit integers:

```sh

```
