# VERITAS-ETH v3.5.0

- Preserves all source, functions, mathematical research modules and interfaces from v3.4.
- Adds finite child network scope with both owned original halfbits and actual geometric mode-exponent bonds, rather than only original port counts.
- Adds exact factor ownership ledgers and checks every mode has exactly two group endpoints.
- Adds configurable finite child-scope resource guard, fail-closed verification and independent source replay.
- Adds `veritas-eth35`, API endpoints, browser demo, adversarial tests, validation and docs.

**Not implemented:** D.4.4's actual shrinking child packet tensors, the M/8 child size proof, or the complete subexponential algorithm. No such claims are made.
