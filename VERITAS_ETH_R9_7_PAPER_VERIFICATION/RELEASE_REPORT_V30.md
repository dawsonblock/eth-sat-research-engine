## Interpretation

These are finite identity checks; the demo D.3 numeric theorem hypotheses are not generally satisfied. The implementation is a conventional separator decomposition and may take exponential time. It does not construct D.4.4 geometric-tile mode-selected child tensors, enforce an M/8 reduction, or prove any asymptotic runtime improvement. Code is a research prototype, not cryptographic proof.
