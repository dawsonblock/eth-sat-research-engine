# v2.9 finite tapered Hermite and extension-ring rank-one modes

## Mathematical scope

These independent small-instance references validate two **components** of the paper, not its fast recurrence.

### Tapered schedule

With packets of size `L=2^a`, an input network with `M` wires and user-selected positive `u`, set `h=ceil(3M/u)`. For nonzero `t∈[-L,L-1]` with `i=v₂(t)`, set `q_t=h max(0,u-i)` and `p_t=p+8h (L/2^i)+8M(a+1)`. The constant-term reconstruction requires the number of available local Taylor coefficients to exceed the input degree bound `M(2L-1)`. These are manuscript-style formulas; scaled concrete inputs are **not automatically eligible** under the theorem's large-parameter preconditions.

The finite reference uses the **first `degree+1`** local Taylor coefficients in the specified node order, retaining a prefix per node. If `A` maps polynomial coefficients to those local Taylor data, rational weights solve `Aᵀ w=e₀`. Rather than illegally inverting even integers modulo `2^p`, choose `g=max(0, max(-v₂(w_j)))` and compute `2^g*w_j` modulo `2^(p+g)` where every denominator is odd. A supplied local coefficient with precision `p_t` is sufficient when `p_t>=p-v₂(w_j)`. The recovered integer is the scaled sum divided by `2^g`. Reconstructing a polynomial at input precision `p` cannot be justified when these conditions fail. The implementation also checks that the scaled residue sum is divisible by `2^g`.

**This is a bounded, degree<=31 rational reference**. Working guard precisions are bounded explicitly. It does not give the paper's asymptotic running time, and a polynomial-oracle comparison is not a general independent mathematical proof of arbitrary input jets.

### Extension-ring modes

For an independently verified finite D.3 packet certificate, the Cauchy entry `W_xy(T)` is generated by the **deleted-factor** polynomial. Substitute `T=t+2^(a+1)z` and map its integral 2-adic coefficient vector to `(Z/2^p)[U]/f`. This produces a ring-valued Taylor jet over the truncated polynomial parameter. Never invert an even denominator in the residue ring.

Within each packet, classify rows and columns by their coordinate-`v₂(t)` D.3 symbols. Keep same-group `W` entries as direct jets. For each cross-group column, obtain the exact vector of jets to all target-group rows. Columns with identical vectors may be combined into **one rank-one mode**. The column form is the sum of those column variables, while the row form is the original coefficient-jet vector. This equality is exact. The reported mode weight is the **actual minimum 2-adic valuation** over every coefficient. If all coefficients are zero modulo `2^p`, the mode is omitted. A separate checker recomputes every original Cauchy coefficient and its source/target membership and checks that the local-plus-mode representation is identical coefficientwise.

This finite mode construction is purposely different from the manuscript's geometric-tile low-weight generator: **no finite-rank decomposition here implies `exp(O(M/sqrt(log M)))` time**. It is used to test the extension-ring and mode-checker infrastructure before attempting D.4.4.

## How to run

```bash
pip install -e '.[test]'
veritas-eth29 tapered --wires 2 --a 1 --u 1 --precision 8 --coefficients-json '[12,9,-3,0,2]'
veritas-eth29 modes --edges-json '[[0,0],[1,1],[0,1],[1,0]]' --a 1 --r 2 --precision 8 --extension-degree 4 --jet-length 3 --output v29-certificate.json
veritas-eth29 check-modes --certificate v29-certificate.json
python scripts/validate_v29.py
```
